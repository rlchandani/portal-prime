Tools, thoughtfully opened.

A browser design reference for eleven ordinary tools plus Advanced Speed test, a retained launcher shell, contextual sheets, and simulated tool flows. The Tools body and rail are transparent over the launcher wallpaper, with no top All tools button. The active bottom Tools tab returns to the library preserving filter and scroll; switching other tabs and back retains the selected tool in this mock.

These references use a 2160 × 1440 pixel canvas matching the Portal+. All browser data and hardware actions are synthetic or simulated. Actual native checks and performance measurements are available in the separate device evidence gallery. These browser captures do not establish microphone/TTS operation, compatible household RTSP streams, or feed accuracy.
