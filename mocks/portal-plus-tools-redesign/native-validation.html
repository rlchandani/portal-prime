Validation results

Browser mock

Native device
Final expanded smoke passed on the benchmark build: 405 assertions, all true (0 false), 66.435 seconds. This is functional run duration, not a rendering performance measurement.

Real memo checks covered Record, Stop, Play, Stop, Delete Cancel and Delete confirmation, restoring the initially absent voice file.

Fingerprints of six configuration stores stayed unchanged. The voice file and microphone grant were preserved; ephemeral lamp controls were restored.

Final warmed switching trials measured p95 frame durations of 52.64 / 39.15 / 38.13 ms. The third trial improved about 38% over the 61.99 ms baseline. The stricter 16.67 ms p95 target remains unmet; consistent 60 fps is not established. These are Android gfxinfo FrameCompleted − IntendedVsync durations, not physical input latency.

Each trial retained 120 valid frames. After 25 additional four-tool cycles, sampled PSS fell from 108,632 to 105,832 KiB; no frames rendered during the 2.046-second idle sample. This is a non-debuggable benchmark build with normal JIT and retained profiles, not a cleared cold-install or long-running leak certification.
