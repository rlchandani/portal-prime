What it is. Quick controls is a Home widget of big shortcut tiles: Hey Jarvis, plus either your Home Assistant dashboard or the Home Assistant app.

What setup changes. Nothing on the widget itself. It only reads which apps are installed and whether a dashboard address is saved, then decides which tiles appear.

End effect on Home. Each tile is a door. It opens Jarvis, the dashboard in the browser, or the Home Assistant app. No tile switches a light by itself.

Simulated device

Pretend this Portal has these installed. Nothing here touches a real device.

Change the address on the Portal itself: Settings, then Connections, then Home Assistant dashboard.
