# Portal+ slideshow research brief

Research completed October 7, 2026. Open this directory through the existing local
preview server at `http://127.0.0.1:8765/portal-plus-slideshow-research/`.

This is a research brief and synthetic framing illustration, not the final
slideshow mock, a detector demonstration, or a Portal performance benchmark.
No application code or slideshow settings were changed for this research.

The authoritative reports are in `docs/design/`:

- `portal-plus-slideshow-research.md`: combined recommendation and device evidence.
- `portal-plus-slideshow-face-research.md`: existing detector, geometry and offline options.
- `portal-plus-slideshow-pipeline-research.md`: sources, persistence, decode and scheduling.

Copies are included here for download. Keep them synchronized with those sources.
`device-summary.json` contains sanitized host observations; its scope field
explains why these are not a complete WebView FPS benchmark.
`source-probes.json` records deterministic probes against the current engine
source, including a deliberately delayed-image fixture. They are source evidence,
not detector or hardware measurements.

The page uses local code and inline illustrated subjects. No household photographs,
credentials, full device logs or native screenshots are included.
