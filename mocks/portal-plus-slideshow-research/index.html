Three dependable presentations first.

Smart frame

One image and a small, safe drift. Keep the photograph still when movement would cut into a protected region.

Portrait pair

Two compatible portraits from an album or nearby dates. A single framed portrait when there is no suitable partner.

Framed photograph

The whole image on Meta charcoal. Preserve group photos, panoramas, artwork and scans without a live blurred duplicate.

Aim to start at 30 seconds per image, a 0.8–1.2 second dissolve and no more than about 3% additional zoom when safe. These are proposed tuning values. Existing styles remain available through a compatibility path until replacements are tested.

What the investigation found.

Motion stops early

Some current zooms last 12–13 seconds, even with a 30-second photo interval. A source probe verified the 17-second still remainder.

Images can arrive late

The actual scene scheduler removed an outgoing fixture after 1.7 seconds while the next image was still unready. A replacement must be ready before the old scene leaves.

Face data is incomplete

The project already bundles ML Kit. Some WebView styles use its cached focal point; Classic does not. Bounds, orientation and full-motion protection need a shared contract.

Memory needs a real bound

A 4,000 × 3,000 native photo can still decode at full size, costing 45.78 MiB before scratch and GPU copies. Compressed cache size does not bound pixel memory.

A smaller rendering contract.

  1. Keep the sources.Local folders, shared albums, Immich, WebDAV and SMB, with their authentication and video eligibility.
  2. Prepare the next image.Acquire once, normalize orientation, bound decoded pixels, reuse bytes for optional background analysis.
  3. Validate framing and motion.Keep padded detected regions visible. Show the whole image when analysis is uncertain or a safe crop cannot fit.
  4. Replace only when ready.One transition owner, bounded lookahead, cancellation on exit and the previous valid photo during slow or offline loading.

Recommended destination: a native stage for the default compositions, with the current WebView styles retained as a tested compatibility path. Android 10 supports the required native image and transform primitives; newer RenderEffect blur and AGSL APIs are outside this device’s API level.

What must pass before this becomes the new default?

Complete-path face containment, EXIF orientations 1–8, no blank transitions, prompt exit, rapid-swipe cancellation, slow/offline sources, image/video handoff, and a two-hour memory soak. Measure moving phases separately, aiming for p95 within 16.7 ms and p99 within 33.3 ms. These targets require a controlled device prototype.
