# Polaroid clock-reservation proof

The production mode uses the existing measured photo-layout area for complete
rotated paper prints. Nine frozen regressions and the existing eleven lifecycle
cases pass.

`native-fixture/build.sh` embeds a caller-selected exact optimized APK. The
permission-free fixture measures generated hidden reservation rectangles and
publishes the existing native-to-CSS bridge format. It executes the actual
Polaroid renderer, then checks paper clearance and all photo-corner and paper
pixels. The unchanged baseline has seven intersections; the candidate has zero.
Strict resource admission, compositor fences, bounded watchdog and retirement
remain. Root owns any device execution.

Images contain generated photos only. Evidence does not establish real native
clock geometry, Android resize, production scheduler, API28, Living visuals or
performance. Original 08:48:03–09:18:03 UTC clock and earlier parked scopes remain.
