Quality and release gates

All catalog states and useful sizes must be selectable. Verify dark/light themes, keyboard focus, text at 150%, and widths of 390, 1440 and 2160 CSS pixels. Main review controls and actions have a 48 px minimum target. No polling, external assets or backdrop blur.

Browser measurements are review-tool measurements. Native performance requires Family Area traces and identical before/after scenarios. Approval precedes native design implementation; a release requires a version bump, signed build, passing tests and device verification.

Engagement, retention and NPS need real user observations. No scores are fabricated.

Review sequence

  1. Select a widget, then compare sizes and states.
  2. Use Portal view for focused layout review.
  3. Tap a preview action to inspect its intended behavior.
  4. Approve a native pilot before the remaining variants are implemented.
