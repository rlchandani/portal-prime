Device and ownership boundaries

Third-party apps, YouTube Music, Portal calls, Android permissions, Wi-Fi, Bluetooth, date/time, language, accessibility, storage, provider widgets and package uninstall retain their current interfaces. Each handoff is represented in the mock. Those owners’ internal pages are outside Immortal’s design contract; review annotations are not new product screens.

Device evidence: 2160 × 1440, 180 dpi, Android 10 / API 29, Immortal debug 1.64 / 58, 25 launchable Activities, 20 boot-selectable packages, 12 curated installed apps, and all nine configured widget families. Private setting values and entity names/IDs are omitted. The 42 observed offline voice labels are represented as public choices; native voice IDs must be discovered from the TTS engine. Sample inputs remain in browser memory only.

Automatic and legacy fields are explicitly retained. Battery Saver is unavailable on the connected Portal+ because it has no battery. The eight derived registry entries remain native status fields; they are not editable controls.

The authenticated live settings schema was not accessed: automatic approval review rejected reading and reusing stored authentication tokens. Coverage uses the source registry and read-only public device evidence.
