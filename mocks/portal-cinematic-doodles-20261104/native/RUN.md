# Cinematic doodle asset fixture

Build with `bash build.sh <exact-candidate-performance.apk>`, Android SDK36 and the local debug keystore. The fixture embeds that APK as `assets/source.apk` and never loads installed launcher state.

The coordinator targets the authorized Portal explicitly, launches `com.immortal.graphitefixture/.GraphiteActivity`, retrieves `report.json` and four generated PNGs from its external files directory, then uninstalls it and verifies package/process absence.

Require four ready scenes, decoded480x360SVG, contain fitting, static repeat480x360 background, zero unknown resources and PixelCopy margin variation. The owned data main frame is allowed and the fixed local favicon returns404; all other requests must match the exact embedded asset allowlist or generated photos. There is no INTERNET permission.
