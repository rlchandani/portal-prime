Immortal — Dusk Aurora

The approved redesign direction: a dusk-aurora wallpaper, dark frosted-glass widgets that each render their own miniature world, and the gradient-squircle icon system. One shared design system (aurora.css + aurora-icons.js) across every screen. Click any mock; F11 for fullscreen.
Portability: everything here maps to existing Compose primitives — glass = LiquidGlass with darker tint values, wallpaper = layered Brush gradients + blur, widget skies/dials = per-widget Brush/Canvas, icons = gradient squircle drawables + white vector glyphs, grouped lists = existing settings rows recolored to the dark palette. No capability the Portal (Android 10, no GMS) lacks.
