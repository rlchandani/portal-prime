# Owned generated legacy Gallery Wall acceptance

Build with `./build.sh /absolute/path/to/exact-candidate-performance.apk`. The parent owns device install/run/collection and retirement. Fixture package: `com.immortal.galleryfixture`; Activity: `.GalleryActivity`. Manifest declares zero permissions.

Four scenes: single landscape, single portrait, mixed six, and ten landscape cells receiving an eleventh generated same-bucket landscape photo with a different aspect ratio through the actual Gallery swap routine. Replacement scene waits for visible, settled incoming photo then pauses its owner. It does not replace production timers or mutate CSS/photo geometry.

Each visible photo has four generated colored corner witnesses (72 total). Native PixelCopy reads them with summed RGB distance <=18, and scans outer/root matte plus available replacement-cell letterbox margins for quiet SVG lines. Computed gates require known prepared photo URLs, whole-photo contain fit, visible settled images, opaque #1c1b19 photo backing with owned photo over dark SVG, original #1c1b19 matte, loaded 480x360 dark SVG/repeat, zero unknown requests and no bootstrap errors. Capture follows WebView compositor completion. One 45-second watchdog owns the whole run. Reports and generated PNGs are written to fixture external-files storage; replacement-letterbox pixels also reject generated outgoing photo colors. Completion destroys its WebView and closes the embedded uninstalled APK.

Scope: generated legacy Gallery Wall appearance and same-bucket replacement only. No actual FaceRenderer, native SlideshowStage Gallery Print/Spread, native clock, resize, motion, scheduler or performance claim.
