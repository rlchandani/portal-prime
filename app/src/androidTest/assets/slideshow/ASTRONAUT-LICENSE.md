# NASA astronaut fixture

`astronaut.png` is the 512 × 512 image of astronaut Eileen Collins distributed
as `skimage.data.astronaut()`. Credit: NASA.

Scikit-image documents this image as having “No known copyright restrictions,
released into the public domain.” It identifies NASA Great Images as the source.
The image is included only in the test APK for local bundled face-detector checks.
