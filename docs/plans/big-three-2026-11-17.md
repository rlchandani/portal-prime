## Quality bar (every feature)
- Matches its mock's visual language and the refined Home tokens (ApprovedHomePalette, Hearthpane
  mark, 1.5 dp outlines, ≥64 dp targets, light + dark). No placeholder-looking screens.
- Perf on Family Portal (gfxinfo): open ≤1 janky frame, interactions p90 <16 ms / p99 <32 ms,
  animations paused when screen dims, no memory growth after leaving (dumpsys meminfo).
- Every state from the mock exists: loading, empty, offline, error, stale, permission.
- JVM tests for all logic (parsers, policies, state reducers), 80%+ on new logic.
- Code review (CRITICAL/HIGH fixed) before merge. Small files (<400 lines), immutable state.
- Device-tested silently (quiet hours: STREAM_MUSIC 0 and restore; no chimes 22:00–08:00).

- Portal Mini parity (owner 2026-11-18): same perf/quality targets on the Mini (800×1280, rotates) — measure there too.
