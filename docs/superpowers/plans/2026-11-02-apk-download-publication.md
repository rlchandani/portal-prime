Original discovery clock: **22:11:39–22:41:39 UTC**, 2 November 2026, including
discovery, implementation, verification, deployment and cleanup. No parked issue

Store and self-update downloads currently write directly over their cached APK.
Generated real TCP tests reproduced acceptance of empty/incomplete responses;
two explicit preservation tests found four original bytes replaced by a
123-byte truncated response. This is distinct from metadata response budgeting.

Keep APK bytes streaming to disk. Reuse the existing fleet temporary-file writer
so only complete, nonempty responses replace the destination. Validate announced
length when available, close input/output before publication and disconnect the
connection on every terminal path. Preserve headers, timeouts, redirects,
installer behavior, signatures, settings and wire contracts. No arbitrary APK
size cap, digest promise or retry is introduced.
